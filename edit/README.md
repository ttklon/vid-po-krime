# Учебная монтажная версия ППНМ — версия 2

Первая сборка отклонена по содержанию. Правильный вечерний `IMG_4701.MOV` получен, сохранён и технически проверен. Дневной `IMG_4682.MOV` заменён **целиком**, а не обрезан для сокрытия адреса. Новый блок 00:00–09:35 сохранён без внутренних склеек: прибытие с адресом, весь подъём, вход, рассказ, стулья, подробный показ с манекеном, перемещение и объявление паузы.

План: `edit/plan.json`. Подробный разбор и ограничения: `review/revision-2.md`. Плановая длительность — **1111,1 секунды (18:31,1)**, 1080p30, H.264 CRF 18, AAC stereo 48 кГц / 192 кбит/с. Использованы 7 из 9 MOV. Все оригиналы и отклонённый первый MP4 сохранены. Статус завершения экспорта определяется процессом, а не наличием плана.

## Оформление и обработка

Два простых титра: белый **PT Astra Serif Regular** на чёрном фоне. Настоящий шрифт ParaType и лицензия SIL OFL — в `assets/fonts/`. Вступление обозначает учебную монтажную версию, заключение честно сообщает, что полнота объяснения прав по записи не подтверждена.

HLG/BT.2020 преобразуется в SDR/BT.709 с Hable tone mapping. Вечерний блок получает очень небольшую коррекцию gamma/saturation. Звук: high-pass 65 Гц, мягкий `afftdn` (4 дБ), двухпроходный loudnorm -16 LUFS / -1,5 dBTP. На первом измерительном проходе применяется та же очистка, что и на втором. На концах сегментов — 15 мс fade от щелчков.

Вечерний блок стабилизируется консервативным vidstab: smoothing 8, сдвиг не более 6 пикселей, поворот не более 0,003 радиана, фиксированное увеличение 2%. Это слегка обрезает поле зрения. Отсутствие математических потерь при перекодировании не заявляется. Исходники не изменяются. Пространственное шумоподавление картинки, генерация кадров, оптическая интерполяция, синтез речи и подмена слов не применяются.

## Запуск

```sh
python3 -m venv .venv
.venv/bin/pip install -r edit/requirements.txt
.venv/bin/python tools/render_film.py
```

Сервер слушает `0.0.0.0:8081` (`FILM_PORT` меняет порт). Для просмотра без запуска экспорта: `FILM_SERVE_ONLY=1 .venv/bin/python tools/render_film.py`.

`edit/revision.json` оставлен как история исправления со статусом `resolved`. Если статус не разрешён или план не соответствует второй сборке, автоматический экспорт блокируется. До начала работы сверяются SHA-256 используемых оригиналов с манифестами `videos/`; утраченный локальный исходник восстанавливается из Git-частей.

Промежуточные файлы, анализ движения, измерения звука, контрольные отметки и статус: `.cache/film-render-v2/`. Итог: `.cache/exports/ppnm_v2_1080p_educational.mp4`. Код и план входят в подпись контрольных отметок. Склейка сначала записывается во временный MP4, затем атомарно заменяет имя результата: файл, связанный с архивом hard link, не перезаписывается на месте.

После сборки весь результат декодируется по видео и звуку с `-xerror`; проверяются формат, длительность и отсутствие геометок контейнера. Только после этого открывается просмотр и скачивание. Протокол: `.cache/film-render-v2/export-result.json`; точная карта: `edit-ledger.json`. Техническая читаемость не равна полному ручному просмотру или юридической экспертизе.

## Резервная копия

Для автоматического сохранения должен работать согласованный временный uploader:

```sh
UPLOAD_OPEN_ACCESS=1 python3 upload_server.py
```

Экспорт регистрируется локально через `/api/import-export`: сервер проверяет размер, SHA-256, имя и расположение файла, затем создаёт hard link вместо второй большой копии. Этот маршрут требует отдельный внутренний заголовок с локальным ключом сессии **даже в открытом режиме**. Ключ никогда не передаётся странице просмотра. Произвольные пути и символические ссылки запрещены. Лимиты сессии 16 файлов / 5 ГиБ не обходятся. После регистрации работает прежняя последовательная резервная копия Git-частей по 48 МиБ, с коммитами, push и проверкой удалённой ветки.

Готовность MP4 и готовность GitHub-backup — отдельные статусы. Ошибка резервной копии не скрывает готовый MP4. Локальный диск временный; скачайте результат после готовности. После подтверждения backup оригинал восстанавливается через `restore_video.py` по манифесту в `videos/`.

## Ограничения

Монтаж учебной постановки не удостоверяет непрерывность следственного действия и не выполняет требование преподавателя «без склеек». Произнесённые в исходнике слова «без монтажа» не описывают итоговый файл. Неполное объяснение прав, оговорки и отсутствие подтверждённых кадров подписания нельзя исправить монтажом без подмены содержания. Автоматические расшифровки — черновики, в фильм не вшиваются.

## Тесты

```sh
.venv/bin/python -m unittest discover -s tests -v
```

Тесты не публикуют тестовые данные. Проверяются замена дневного блока, сохранение вечернего целиком, настоящий шрифт и чёрно-белые титры, очистка/измерение звука, HTTP Range, защита и идемпотентность локального импорта, контрольные суммы и состояния резервной копии.
